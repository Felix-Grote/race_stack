Draft & view
How to use
  1. Open map. Select a map and confirm the route name, surface, and maximum speed (Map ▸ Route metadata).
  2. Define road. Add missing walls with Boundary Pencil. Select Drivable Region by clicking inside the road; inspect excluded areas. Boundary strokes only add occupied cells.
  3. Extract. Check the derived (blue) boundaries against the intended drivable road. A completed boundary edit refreshes extraction automatically; Extract lets you rerun it manually.
  4. Set direction. Draw one closed loop with Route Pencil, or choose Suggest Route. Inspect its direction arrows; Reverse Direction changes only traversal order — the yellow guide sets direction and section cuts; it is not exported.
  5. Review. Preview Route; inspect the green section walls and derived centreline, gates and starting zone. If Validate is used to try an alternate wall thinning, Preview Route again — approval binds the preview.
  6. Approve and export. Approve Route for the specific preview, then Export Route. Any geometry or metadata edit revokes approval. Save Draft persists editable annotations; it is not approval.
Controls & safety

Click to add points; double-click to finish a stroke; Escape cancels an unfinished stroke. Wheel zooms at the cursor; Space+drag or middle-drag pans; Fit Map resets the view and never edits the draft. Source PNG/YAML are never written. Hover geometry is local-only. There is no free-space painting. A route preview is NOT a speed-optimized or vehicle-certified racing trajectory.
