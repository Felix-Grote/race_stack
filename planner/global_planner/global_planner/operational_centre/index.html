ForzaETH Operational Centre Help

  

    

      
Annotator
Open a map, place the start and export a validated route.

      
Settings
Apply optimizer values. Changing one marks the trajectories it affects as stale.

      
Logs
Read what the planner did in the last run of a profile, pass by pass, and the stack trace if it failed.

      
Tracks
Generate the driving profiles, then select the layers to compare. Choose one profile for Active Constraints or Wall clearance. Point at the map or graph to inspect the location.

    

    
Times and telemetry are predictions from the vehicle model. The profile presets are provisional.
